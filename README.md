# NLP Linguist Lab 1

## Цель проекта
Настройка изолированного окружения для NLP-проекта и фиксация зависимостей.

## Активация окружения
source .venv/bin/activate

## Версия Python
Python 3.12.3

## NLP-библиотеки и NER-модель

Установленные библиотеки:
- spaCy 3.8.18
- NLTK 3.10.4
- Stanza 1.15.1
- fasttext 0.9.3
- PyTorch 2.15.0+cpu

Модель: ru_core_news_sm 3.8.0.
Источник — официальный репозиторий spaCy.

Для демонстрации распознавания именованных сущностей используется файл ner_demo.py.
Результат работы программы сохранён в output.txt.

Распознанные сущности:
- Анна Петрова — PER (человек)
- Яндекс — ORG (организация)
- Москве — LOC (географическое место)
